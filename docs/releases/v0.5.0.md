# audio-transcribe v0.5.0

This release turns the interactive transcription pipeline into a resilient unattended service while preserving the existing CLI workflow.

Highlights:

- resumable, content-addressed stage checkpoints and per-run manifests;
- SQLite worker queue with atomic claims, retry/backoff, dead-letter handling, crash recovery, and health output;
- named TOML profiles, meeting-note templates, batch enqueueing, and runtime diagnostics;
- strict backend/range validation, normalized-audio cleanup, and concurrent state-file locking;
- backend-specific extras plus the compatible aggregate `ml` stack;
- Linux/macOS CI, scheduled Apple Silicon inference, release checksums, CycloneDX SBOM, and GitHub provenance attestation.

Verification:

- 247 tests passed (one opt-in ML test skipped in the normal suite), 80%+ coverage;
- Ruff, strict mypy, lockfile validation, package build, and core dependency audit passed;
- real synthesized-speech inference passed on Apple M4 with both `mlx` and `mlx-vad`;
- wheel and source distribution were inspected before publication.

The full ML stack remains pinned to the latest WhisperX-compatible Torch family. The known upstream advisories and the trusted-input boundary are documented in `SECURITY.md`.
